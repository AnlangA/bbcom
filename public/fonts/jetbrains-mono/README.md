# JetBrains Mono

Unmodified Regular (400) and Bold (700) WOFF2 files from
[JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304),
distributed under the [SIL Open Font License 1.1](OFL.txt).

These files ship with the application so terminal and data fonts work offline
without requiring a system font installation. The Shell waits for both weights
before xterm.js measures its character cells. Programming ligatures are disabled
in the terminal so serial output retains separate, aligned symbols. Chinese
glyphs use the platform's fallback fonts.
