# ADR-0004: Plugin trust and release gate

- Status: Retired
- Retired: 2026-08-20

The signature, TUF, digest, authorization, marketplace-readiness, and platform
sandbox design previously recorded here was removed. BBCOM no longer claims to
authenticate, attest, authorize, or sandbox plugin packages.

The current runtime is documented by
[ADR-0005](ADR-0005-PLUGIN-PROTOCOL-V2.md).
